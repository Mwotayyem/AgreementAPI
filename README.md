# دليل استخدام واجهة برمجة التطبيقات (API) للاتفاقيات

مشروع ASP.NET Core Web API لإدارة الاتفاقيات والمواد في قاعدة بيانات أوراكل.

## المميزات

- **إدخال/تحديث اتفاقية**: `POST` لإدخال اتفاقيات جديدة أو تحديث الموجودة.
- **التحقق من تكرار المواد**: يمنع إضافة مادة إذا كانت مرتبطة باتفاقية أخرى **فعالة** (Status=1).
- **تحديث مادة**: `PUT` لتحديث بيانات مادة معينة.
- **توليد تلقائي للأرقام المتسلسلة**: `TRN_SERIAL` يتم توليده تلقائياً (MAX+1).
- **كشف تغييرات المادة**: يسجل نوع التغيير (باركود، سعر، اسم) برقم `TRN_TYPEID` المناسب.
- **رسائل تفصيلية**: يعيد الـ API رسائل عربية واضحة حول كل ما تم تغييره.

## 🧪 دليل الاختبار باستخدام Postman

تأكد أولاً أن المشروع يعمل على الرابط: `http://localhost:5079`

### 🔹 اختبار 1: إدخال/تحديث اتفاقية (Insert/Update Agreement)

يقوم هذا الإجراء بإدخال اتفاقية جديدة مع موادها، أو تحديث اتفاقية موجودة.

**سلوك النظام (Updated Logic):**
- **الدمج (Merge Strategy):** النظام **لا يحذف** أي مواد قديمة عند التحديث.
- **إضافة/تحديث:**
  - إذا كانت المادة موجودة في الاتفاقية الحالية ← يتم **تحديث** بياناتها (شرط أن تكون الاتفاقية **غير فعالة** Status=0).
    - إذا كانت الاتفاقية **فعالة** (Status=1) ← يتم **تخطي** التحديث ومنع التغيير.
  - إذا كانت المادة غير موجودة في الاتفاقية الحالية ← يتم **إضافتها** (جديدة).
- **التحقق من التعارض:**
  - يتم فحص كل مادة: هل هي موجودة في **اتفاقية أخرى فعالة** (`Status=1`)؟
  - إذا نعم: يتم **تخطي** هذه المادة (لا تضاف ولا تحدث) وتظهر رسالة تحذير، مع الاحتفاظ بباقي المواد.

**في Postman:**

1. افتح **Request جديد** (New → HTTP Request)
2. اختر Method: **POST**
3. أدخل الـ URL:
   ```
   http://localhost:5079/api/agreement/insert
   ```
4. اذهب إلى تبويب **"Body"**:
   - اختر **raw**
   - اختر **JSON** من القائمة المنسدلة
   - الصق هذا الكود:

```json
{
  "AGREEMENT_NO": "2020310193",
  "ITEMS": [
    {
      "ITEMNO": "10691088",
      "BARCODE": "6212900018694",
      "ITEMSHORTNAME": "Nescafe",
      "ITEMTAX": 16,
      "ITEMPRICE": 1.75,
      "ITEMSTOP": 0,
      "TRN_TYPE_PRICE": 1
    },
    {
      "ITEMNO": "10691088",
      "BARCODE": "6212900018694",
      "ITEMSHORTNAME": "Nescafe",
      "ITEMTAX": 0,
      "ITEMPRICE": 1.5,
      "ITEMSTOP": 0,
      "TRN_TYPE_PRICE": 8
    }
  ],
  "COMP_CODE": "999494",
  "AGR_STDATE": "25/01/2021",
  "AGR_ENDATE": "24/01/2022"
}
```

5. اضغط **"Send"**

**النتيجة المتوقعة:**

```json
{
  "success": true,
  "message": "✅ تم تحديث الاتفاقية 2020310193 بنجاح مع 2 مادة\n✓ تم العثور على الاتفاقية 2020310193 - سيتم التحديث\n✓ تم حذف 2 سجل قديم\n✓ تم إدراج المادة 10691088 - Nescafe (TRN_SERIAL=450)\n✓ تم إدراج المادة 10691088 - Nescafe (TRN_SERIAL=451)\n✅ تم حفظ جميع التغييرات في قاعدة البيانات",
  "data": {
    "agreementNo": "2020310193",
    "itemCount": 2
  },
  "errors": []
}
```

### 🔹 اختبار 2: تحديث مواد (Batch Update Items)

يقوم هذا الإجراء بتحديث بيانات مادة واحدة أو مجموعة مواد. يكشف النظام تلقائياً ما تغير (باركود، سعر، اسم) ويسجل الحركة المناسبة في جدولي `MCEPOS_ITEMS` و `MCEPOS_AGREEMENT`.

**المميزات:**
- يقبل كائن واحد أو قائمة (Array).
- إذا كانت مادة غير موجودة، يتم تخطيها مع إرجاع رسالة خطأ، ويستمر في تحديث باقي المواد.
- يتم تحديث الجدولين معاً عند تغيير أي بيانات.

**في Postman:**

1. افتح **Request جديد**
2. اختر Method: **PUT**
3. أدخل الـ URL:
   ```
   http://localhost:5079/api/agreement/update-item
   ```
4. **Body** (raw → JSON):

**مثال لتحديث مجموعة مواد:**

```json
[
    {
      "ITEMNO": "10691088",
      "BARCODE": "6212900018694",
      "ITEMSHORTNAME": "Nescafe Gold",
      "ITEMTAX": 16,
      "ITEMPRICE": 2.50,
      "ITEMSTOP": 0,
      "TRN_TYPE_PRICE": 1
    },
    {
      "ITEMNO": "999999", 
      "BARCODE": "111",
      "ITEMSHORTNAME": "Missing Item",
      "ITEMTAX": 0,
      "ITEMPRICE": 1,
      "ITEMSTOP": 0,
      "TRN_TYPE_PRICE": 1
    }
]
```

5. اضغط **"Send"**

**النتيجة المتوقعة (نجاح جزئي):**

```json
{
  "success": true,
  "message": "✅ تم معالجة 2 مادة (تم تحديث 1)\n✓ تم تحديث المادة 10691088: السعر, الاسم (TRN_TYPEID=4)\n❌ المادة 999999 غير موجودة - تم تخطيها",
  "data": {
    "updatedCount": 2,
    "items": [
      "10691088",
      "999999"
    ]
  },
  "errors": [
    "المادة 999999 غير موجودة"
  ]
}
```

**ملاحظة:** يمكن إرسال كائن واحد فقط (بدون أقواس المصفوفة `[]`) وسيعمل النظام أيضاً.

### 🔹 اختبار 3: تحديث مادة غير موجودة (Error Case)

جرب تحديث مادة غير موجودة للتحقق من رسالة الخطأ.

**Body:**

```json
{
  "ITEMNO": "99999999",
  "BARCODE": "1234567890123",
  "ITEMSHORTNAME": "Test",
  "ITEMTAX": 0,
  "ITEMPRICE": 1,
  "ITEMSTOP": 0,
  "TRN_TYPE_PRICE": 1
}
```

**النتيجة المتوقعة:**

```json
{
  "success": false,
  "message": "❌ المادة 99999999 غير موجودة في قاعدة البيانات",
  "data": null,
  "errors": [
    "المادة 99999999 غير موجودة"
  ]
}
```

## ملاحظات هامة

1. **الـ Headers**: لا حاجة لإرسال `Content-Type: application/json` يدوياً بعد الآن، السيرفر يقبل الطلبات تلقائياً، لكن إضافتها ممارسة جيدة.
2. **أنواع الحركات (TRN_TYPEID)**:
   - **1**: إدخال مادة (INSERT ITEM)
   - **2**: تحديث باركود (UPDATE BARCODE)
   - **3**: تحديث سعر (UPDATE PRICE)
   - **4**: تحديث اسم (UPDATE ITEM NAME)
   - **8**: إدخال اتفاقية (INSERT AGREEMENT)
